# Aufgaben und offene Prüfungen

## Öffentliche Quellfassung – erledigt

- [x] Allgemeine Dokumentation auswählen und private Rechnerdaten ausschließen.
- [x] Quellen, Cargo-Dateien, Konfigurationen, Icon und Lizenzen vollständig übernehmen.
- [x] Dateiauswahl, Archive und neue Git-Historie vor Veröffentlichung prüfen.
- [x] Quellfassung auf GitHub veröffentlichen und Remote-Inhalt vergleichen.
- [x] README für Repository-Besucher strukturieren und Dokumentationslinks aktualisieren.

## Noch offen

- [ ] Fertiges öffentliches Linux-x86_64-Download-Paket aus den bereinigten Quellen
  bauen, prüfen und veröffentlichen.
- [ ] NVIDIA-/Intel-Messwerte auf entsprechender realer Hardware prüfen.
- [ ] X11-Fensterzuordnung und hohe Skalierung real prüfen.
- [ ] Hotplug von Laufwerken und GPUs während der Nutzung prüfen.
- [ ] Weitere Distributionen und Architekturen bei Bedarf auswählen und testen.

Automatisierte Tests ersetzen diese Prüfungen nicht. Die offenen Punkte sind
keine Zusage für einen Veröffentlichungstermin.
